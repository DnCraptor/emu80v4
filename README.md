# Корвет (ПК8020) для Murmulator (порт Emu80 v4)

Специализированная прошивка эмулятора **Корвета (ПК8020)** для плат Murmulator на
микроконтроллере RP2040 (Raspberry Pi Pico) и RP2350 (Raspberry Pi Pico 2).

Поддерживается только сборка из корневого `CMakeLists.txt` через Pico SDK/CMake.
Техническое задание и журнал работ — в `vector06c_refactoring_plan.md`
(историческое имя файла сохранено с момента старта порта).

---

## Как выбрать прошивку (.uf2)

Имя файла кодирует плату, чип, частоту и способ вывода изображения:

```
<плата><чип>-korvet-<МГц>-<видео>-<версия>.uf2
```

**Плата (первые 2 символа):**

| Код  | Плата             |
|------|-------------------|
| `m1` | Murmulator 1.x    |
| `m2` | Murmulator 2.0    |
| `z0` | Waveshare PiZero  |
| `PC` | Olimex PICO-PC    |
| `DV` | Pimoroni Pico DV  |

**Чип:**

| Код  | Микроконтроллер  |
|------|------------------|
| `p2` | Pico 2 — RP2350  |
| `p1` | Pico — RP2040 пока нет готовых сборок   |

**Способ вывода изображения:**

| Суффикс         | Выход                                                                 |
|-----------------|-----------------------------------------------------------------------|
| `VGA`           | Аналоговый VGA (резисторный ЦАП), 800×600                              |
| `HDMI-DVI`      | Цифровой HDMI/DVI через libdvi (PicoDVI), 800×600@60. Системная частота жёстко 400 МГц |
| `TV-SOFT-PAL`   | Программный композит **PAL** (RCA/«тюльпан») — для обычного телевизора |
| `TV-SOFT-NTSC`  | Программный композит **NTSC** (RCA/«тюльпан»)                          |
| `TV-RGB`        | Вывод на RGB[s] **PAL** (разводка, как у VGA), 800×600@60. Системная частота жёстко 448 МГц |

**Примеры разбора имени:**

- `m1p2-korvet-400-HDMI-DVI-0.6.2.uf2` — Murmulator 1.x, Pico 2 (RP2350), 400 МГц, цифровой HDMI/DVI
- `m2p2-korvet-440-TV-SOFT-PAL-0.6.2.uf2` — Murmulator 2.0, Pico 2 (RP2350), 440 МГц, программный композит PAL
- `m1p2-korvet-440-TV-SOFT-NTSC-0.6.2.uf2` — Murmulator 1.x, Pico 2 (RP2350), 440 МГц, программный композит NTSC

### Что выбрать под свой монитор

- **VGA-монитор** → `VGA`.
- **HDMI-монитор/телевизор** → `HDMI-DVI` (частота при этом зафиксирована на 400 МГц).
- **Обычный телевизор по композиту** (RCA): для нашего стандарта — `TV-SOFT-PAL`; `TV-SOFT-NTSC` — если телевизор/монитор ждёт NTSC.

Плата (`m1`/`m2`/`z0`/`PC`/`DV`) в имени файла должна совпадать с вашим железом.
На Pimoroni «Pico DV Demo Base» (`DV`) вывод изображения только `HDMI-DVI`. Звук
в сборках `HDMI-DVI` на RP2350 идёт по самому HDMI всегда (48 кГц, пересчёт из
50 кГц микшера эмулятора), независимо от локального выхода; на этой плате
параллельно работает распаянный ЦАП PCM5100A (линейный выход).

## Установка

1. Зажмите кнопку **BOOTSEL** на Pico 2 и подключите плату по USB.
2. Появится накопитель `RP2350`.
3. Скопируйте на него нужный `.uf2` — плата перезагрузится сама.

## Быстрый старт

После сброса и прохождения встроенных тестов, **без подключённых образов дисков,
запускается встроенный Бейсик Корвета**. Для запуска прикладных программ обычно
нужно подключить образ диска в формате `.kdi` (поддерживается и `.fdd`):

1. `Alt+A` — смонтировать образ в дисковод **A** (или через меню). Загрузка с
   диска A происходит автоматически после сброса.
2. После старта операционной системы CP/M наберите `DIR` для списка файлов либо
   имя программы для её запуска.

Магнитофонные операции перехватываются эмулятором (формат `.cas`); чаще всего это
используется в Бейсике командой `LOAD"CAS:"`.

## Управление и горячие клавиши

Главное меню открывается и закрывается клавишей **Alt**. Через меню доступны
загрузка файлов, монтирование дисков и все настройки. Ниже — работающие
сочетания клавиш.

### Меню и система

| Клавиши            | Действие                                                        |
|--------------------|-----------------------------------------------------------------|
| `Alt`              | Открыть / закрыть главное меню                                  |
| `↑ ↓ ← →`          | Навигация по меню                                               |
| `Enter` / `Space`  | Выбрать / изменить пункт                                        |
| `Esc`              | Назад / закрыть меню                                            |
| **`Ctrl+Alt+Del`** | **Жёсткая перезагрузка устройства (watchdog).** Срабатывает всегда — даже при открытом меню или диалоге |
| `Alt+F11`          | Быстрый сброс эмулируемой машины                               |
| `F1+F11`           | Штатный быстрый сброс Корвета                                   |
| `F11`              | Полный сброс машины                                            |

### Файлы, диски, лента

| Клавиши          | Действие                                          |
|------------------|---------------------------------------------------|
| `Alt+L`          | Загрузить файл                                    |
| `Alt+F3`         | Загрузить и запустить                              |
| `Alt+A`          | Смонтировать образ (`.kdi`/`.fdd`) в дисковод A    |
| `Alt+B`          | Смонтировать образ (`.kdi`/`.fdd`) в дисковод B    |
| `Alt+T`          | Перехват ленты (tape redirect) вкл/выкл           |

### Снимки состояния (snapshots)

| Клавиши                | Действие                          |
|------------------------|-----------------------------------|
| `Left Win + F1…F12`    | Сохранить снимок в слот 1…12       |
| `Right Win + F1…F12`   | Загрузить снимок из слота 1…12     |

### Видео и раскладка

| Клавиши   | Действие                    |
|-----------|-----------------------------|
| `Alt+C`   | Цветной / чёрно-белый режим |
| `Alt+Q`   | Раскладка QWERTY            |
| `Alt+J`   | Раскладка ЙЦУКЕН            |
| `Alt+K`   | «Умная» раскладка           |

### Сдвиг картинки на экране

Подстройка положения изображения под конкретный монитор/телевизор — цифровыми
клавишами на numpad. Настройка сохраняется отдельно для каждого режима вывода
(см. раздел «Настройки»).

| Клавиши        | Действие                                    |
|----------------|---------------------------------------------|
| Numpad `*` `/` | Сдвиг картинки по горизонтали (вправо/влево) |
| Numpad `+` `-` | Сдвиг картинки по вертикали (вниз/вверх)     |

Когда открыто главное меню, те же клавиши двигают **само меню** (чтобы оно и
файловый диалог не уезжали за пределы видимой области экрана).

### Джойстик / геймпад

Поддерживаются NES-совместимые геймпады. Кнопки отображаются на клавиши, в том
числе для навигации по меню:

| Кнопка геймпада | Клавиша    | Назначение                        |
|-----------------|------------|-----------------------------------|
| **Start**       | `Alt`      | Открыть / закрыть меню            |
| **Select**      | `Tab`      | —                                 |
| **A**           | `Space`    | Выбор в меню / огонь              |
| **B**           | `Enter`    | Выбор в меню                      |
| D-pad ↑↓←→      | стрелки    | Навигация по меню / направления   |

Таким образом всё меню проходится одним геймпадом: **Start** — открыть,
крестовина — навигация, **A**/**B** — выбрать.

## Настройки

Конфигурация хранится на SD-карте в `/.config/korvet.cfg` и правится через
меню. Значения применяются при старте.

- **Смещение картинки (video offset).** Это подстройка конкретного устройства
  вывода, поэтому хранится раздельно для каждого режима — со своим префиксом
  ключа: `pal_`, `ntsc_`, `vga_`, `dvi_`. Одна SD-карта, переставляемая между
  разными прошивками, больше не смешивает подстройки разных экранов. Положение
  меню на экране считается от этого смещения, поэтому центрируется тоже
  раздельно.
- **Частота RP2350** (меню *System → RP2350 frequency*). Для VGA и композита
  доступны 400/440/480/520/540 МГц. Для `HDMI-DVI` частота зафиксирована на
  400 МГц (значение из конфига игнорируется — libdvi поддерживает строго одну
  частоту на разрешение).
- **Напряжение ядра** (меню *System → Core voltage*).

## Сборка

Нужен установленный Pico SDK. Проверено в VSCode + плагин Raspberry Pi Pico.
Основные ключи задаются вверху `CMakeLists.txt` (или через -D в консольном режиме):

- Способ вывода: `SOFTTV` (+ опционально `TV_NTSC` для NTSC вместо PAL),
  `VGA_DRV` или `HDMI_DVI`.
- `CPU_MHZ` — системная частота (для `HDMI_DVI` принудительно 400).
- `PICO_BOARD` — плата: `murmulator`, `murmulator2`, `olimex-pico-pc`,
  `pimoroni-pico-dv`, `waveshare_rp2350_pizero`.

Готовый `.uf2` появляется в каталоге сборки (bin) под именем по схеме выше.

## Встроенное ПЗУ Корвета

В прошивку зашито штатное ПЗУ Корвета (ПК8020): монитор, встроенный Бейсик и
дисковый загрузчик. Поведение при старте описано выше в разделе «Быстрый старт».

### Дисковый загрузчик ВГ93

Во встроенном ПЗУ присутствует полноценная ветвь загрузки с НГМД на контроллере
ВГ93 (совместим с FD1793). Регистры контроллера в адресном пространстве устройств:

- `18h` — регистр данных ВГ93;
- `19h` — регистр сектора;
- `1Ah` — регистр дорожки;
- `1Bh` — команда/состояние;
- порт видео-ВВ55 (`portB`) — выбор дисковода, стороны и включение мотора.

Загрузчик:

1. включает мотор и проверяет готовность контроллера;
2. читает служебный (загрузочный) сектор в RAM по адресу `8000h`;
3. проверяет контрольную сумму;
4. считывает требуемые сектора;
5. формирует переход по адресу `0000h`.

Если готового образа нет, загрузчик по тайм-ауту передаёт управление встроенному
Бейсику. Поэтому «пустой» Корвет без диска стартует в Бейсик, а с примонтированным
`.kdi`/`.fdd` в дисководе A — грузит систему автоматически после сброса.

### Сброс

- `Alt+F11` — быстрый сброс средствами эмулятора;
- `F1+F11` — штатный быстрый сброс Корвета;
- `F11` — полный (холодный) сброс с повторным прохождением тестов ПЗУ.
