# Специалист для Murmulator

Отдельная прошивка Emu80 v4 для RP2040 и RP2350. Модель машины выбирается в **Model**, процессор — отдельно в **Processor**. После смены модели или процессора машина перезапускается. Выбор сохраняется на SD в `/.config/specialist.cfg`.

| Модель | Встроенное ПЗУ | Программы | Образы лент |
| --- | --- | --- | --- |
| Specialist | Monitor 2 | `.rks` | `.rks` |
| SP-580 | Штатные ПЗУ SP-580 | `.rks`, `.spt`, `.cas`, `.tsx` | `.spt`, `.cas`, `.tsx` |
| MX (RAMFOS) | Штатное ПЗУ MX с RAMFOS | `.cpu` и одноимённый `.i80`, при необходимости `.mon` | `.rfs` |

У всех трёх моделей доступна работа с сигналом ленты в WAV/CSW. У многоблочного SPT после **Load and run** дополнительные блоки остаются на виртуальной ленте. Отдельные файлы дополнительных блоков открываются через **Tape → Load tape image**.

## Управление

| Действие | Клавиша или пункт OSD |
| --- | --- |
| Открыть меню | Alt или Start на геймпаде |
| Выбрать процессор | **Processor → KR580VM80A (i8080)** или **Zilog Z80** |
| Выбрать частоту гостевого CPU | **CPU-Clock**. По умолчанию 2 МГц |
| Запустить программу | **Programs and media → Load and run** или Alt+F3 |
| Загрузить программу | **Programs and media → Load** или Alt+L |
| Заменить ПЗУ | **Programs and media → Boot ROM**. У SP-580 также доступно **High ROM** |
| Вернуть встроенное ПЗУ | **Programs and media → Restore built-in ROMs** |
| Сменить цветовой режим Specialist или SP-580 | **Video → Colors** или Alt+C |
| Выбрать раскладку | **Keyboard** или Alt+Q / Alt+J / Alt+K |
| Сбросить машину | **System → Reset** или Alt+F11 |

Образы ПЗУ в формате `.rom` или `.bin` действуют до смены модели или выключения прошивки. Начальный каталог файловых диалогов — `/specialist`.

На приглашение `PROGRAM?` Monitor 2 нажмите F1–F11, затем Enter для входа в монитор. В мониторе команда `R` открывает диалог выбора входного файла ленты, когда включён **Tape → Redirect tape I/O**. Команда `G` запускает программу по начальному адресу, а `G100` запускает с адреса `0100h`.

### MX (RAMFOS)

MX требует SD-карту. Восемь банков RAM-диска хранятся в файле `/specialist/mx.ramdisk` размером 512 КиБ. Изменения сохраняются при смене кэшируемого блока, сбросе и закрытии OSD. Команда **Load** записывает `PROGRAM.EXE` в пустой первый банк RAM-диска. **Load and run** запускает программу из ОЗУ. Два дисковода открываются через **Programs and media → Floppy disks** и принимают образы `.odi` и `.ord` размером 800 КиБ.

## Сборка

Нужны Pico SDK 2.2.0 с TinyUSB, ARM GNU Toolchain, CMake и Ninja. Пример для Murmulator 2.0 с RP2350 и HDMI:

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DPICO_SDK_PATH=/path/to/pico-sdk -DPICO_PLATFORM=rp2350 \
  -DPICO_BOARD=murmulator2 -DSPECIALIST_VIDEO=HDMI
cmake --build build
```

UF2 создаётся в `bin/<тип сборки>/` в корне репозитория. Для команды выше это `bin/Release/m2p2-specialist-400-HDMI-DVI-0.1.0.uf2`. Для другого сочетания платы, чипа и видео используйте отдельный каталог сборки.

| Параметр | Значения |
| --- | --- |
| `PICO_PLATFORM` | `rp2040`, `rp2350` |
| `PICO_BOARD` | `murmulator`, `murmulator2`, `olimex-pico-pc`, `pimoroni-pico-dv`, `waveshare_rp2040_pizero`, `waveshare_rp2350_pizero` |
| `SPECIALIST_VIDEO` | `HDMI`, `VGA`, `RGB`, `PAL`, `NTSC`. Для Olimex PICO-PC и Pimoroni Pico DV выберите HDMI |

HDMI выводит 800×600 при 60 Гц с двукратным увеличением картинки по обеим осям. RGB использует растр 512×312 и частоту пикселей 8 МГц. Обе сборки работают с системной частотой 400 МГц.

## Реализация

Карты памяти, клавиатурные матрицы и ПЗУ взяты из конфигураций Specialist, SP-580 и MX (RAMFOS) в Emu80 v4. Контроллер ВГ93 и таймер ВИ53 перенесены из ветки Vector-06C с общими для всех моделей драйверами Murmulator. Чтение ОЗУ и ПЗУ и запись в обычное ОЗУ идут через карту страниц CPU. Запись в видеопамять также фиксирует текущий цвет. На RP2040 видеодрайвер получает одну строку за раз. На RP2350 рендерер обновляет изменившиеся строки кадрового буфера. Прошивка использует встроенную SRAM.

Оригинальный эмулятор — [Emu80 v4](https://emu80.org/) Виктора Пыхонина. Условия распространения исходников приведены в `COPYING.txt`.
