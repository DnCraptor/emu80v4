# Специалист для Murmulator

Отдельная прошивка Emu80 v4 для RP2040 и RP2350. Она эмулирует базовый Специалист со встроенным Monitor 2, 48 КиБ ОЗУ, двумя КР580ВВ55 и экраном 384×256. Доступны монохромный, 4-цветный и 8-цветный режимы. Для старта достаточно прошивки. SD-карта нужна для файлов и сохранения настроек.

## Управление

| Действие | Клавиша или пункт OSD |
| --- | --- |
| Открыть меню | Alt или Start на геймпаде |
| Выбрать процессор | **Processor → KR580VM80A (i8080)** или **Zilog Z80** |
| Выбрать частоту гостевого CPU | **CPU-Clock**. По умолчанию 2 МГц |
| Запустить программу | **Programs (.RKS) → Load and run** или Alt+F3 |
| Загрузить программу в память | **Programs (.RKS) → Load** или Alt+L |
| Сменить цветовой режим | **Video → Colors** или Alt+C |
| Выбрать раскладку | **Keyboard** или Alt+Q / Alt+J / Alt+K |
| Сбросить Специалист | **System → Reset** или Alt+F11 |

После выбора другого ядра машина перезапускается с Monitor 2. При наличии SD-карты процессор и другие настройки восстанавливаются при старте из `/.config/specialist.cfg`. Начальный каталог файловых диалогов — `/specialist`.

На приглашение `PROGRAM?` нажмите F1–F11, затем Enter для входа в монитор. В мониторе команда `R` открывает выбор файла ленты, когда включён **Tape → Redirect tape**. Команда `G` запускает программу по начальному адресу, а `G100` запускает с адреса `0100h`. В меню **Tape** также можно выбрать входной или выходной файл. Поддерживаются RKS и записи сигнала WAV/CSW.

## Сборка

Нужны Pico SDK 2.2.0 с TinyUSB, ARM GNU Toolchain, CMake и Ninja. Пример для Murmulator 2.0 с RP2350 и HDMI:

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DPICO_SDK_PATH=/path/to/pico-sdk -DPICO_PLATFORM=rp2350 \
  -DPICO_BOARD=murmulator2 -DSPECIALIST_VIDEO=HDMI
cmake --build build
```

UF2 создаётся в `bin/<тип сборки>/` в корне репозитория. Для команды выше это `bin/Release/m2p2-specialist-400-HDMI-DVI-0.1.0.uf2`. Для другого сочетания платы, чипа и видео используйте отдельный каталог сборки.

| Параметр | Значения |
| --- | --- |
| `PICO_PLATFORM` | `rp2040`, `rp2350` |
| `PICO_BOARD` | `murmulator`, `murmulator2`, `olimex-pico-pc`, `pimoroni-pico-dv`, `waveshare_rp2040_pizero`, `waveshare_rp2350_pizero` |
| `SPECIALIST_VIDEO` | `HDMI`, `VGA`, `RGB`, `PAL`, `NTSC`. Для Olimex PICO-PC и Pimoroni Pico DV выберите HDMI |

HDMI выводит 800×600 при 60 Гц с двукратным увеличением картинки по обеим осям. RGB использует растр 512×312 и частоту пикселей 8 МГц. Обе сборки работают с системной частотой 400 МГц.

## Реализация

Карта памяти и клавиатурная матрица взяты из базовой конфигурации Специалиста в Emu80 v4. Чтение ОЗУ и ПЗУ и запись в обычное ОЗУ идут через карту страниц CPU. Запись в видеопамять также фиксирует текущий цвет. На RP2040 видеодрайвер получает одну строку за раз. На RP2350 рендерер обновляет изменившиеся строки кадрового буфера. Прошивка использует встроенную SRAM.

Оригинальный эмулятор — [Emu80 v4](https://emu80.org/) Виктора Пыхонина. Условия распространения исходников приведены в `COPYING.txt`.
