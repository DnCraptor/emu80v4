# ПК-01 «Львов» для Murmulator

Специализированная прошивка эмулятора **ПК-01 «Львов»** для плат Murmulator на
микроконтроллерах RP2040 (Raspberry Pi Pico) и RP2350 (Raspberry Pi Pico 2).

---

# Как выбрать прошивку (.uf2)

Имя файла имеет вид:

```
<плата><чип>-lvov-<МГц>-<видео>-<версия>.uf2
```

## Плата

| Код | Плата |
|-----|--------|
| `m1` | Murmulator 1.x |
| `m2` | Murmulator 2.x |

## Микроконтроллер

| Код | Микроконтроллер |
|-----|------------------|
| `p1` | Raspberry Pi Pico (RP2040) |
| `p2` | Raspberry Pi Pico 2 (RP2350) |

## Способ вывода изображения

| Суффикс | Назначение |
|----------|------------|
| `VGA` | Аналоговый VGA, 800×600 |
| `HDMI-DVI` | Цифровой HDMI/DVI, 800×600 |
| `RGB-TV` | Аналоговый RGB[s] (SCART/RGB-монитор), системная частота 440 МГц |
| `TV-SOFT-PAL` | Программный композит PAL (RCA) |
| `TV-SOFT-NTSC` | Программный композит NTSC (RCA) |

## Какой файл нужен

| Есть | Используйте |
|------|-------------|
| VGA-монитор | `VGA` |
| HDMI/DVI-монитор | `HDMI-DVI` |
| RGB-монитор / SCART | `RGB-TV` |
| Композитный вход PAL | `TV-SOFT-PAL` |
| Композитный вход NTSC | `TV-SOFT-NTSC` |

Плата (`m1`/`m2`) и микроконтроллер (`p1`/`p2`) должны соответствовать вашему устройству.

---

# Установка

1. Зажмите кнопку **BOOTSEL**.
2. Подключите устройство к USB.
3. Откройте появившийся накопитель.
4. Скопируйте выбранный файл `.uf2`.
5. После копирования устройство автоматически перезагрузится.

# Горячие клавиши

## Меню

| Клавиши | Действие |
|----------|----------|
| `Alt` | Открыть / закрыть меню |
| `↑↓←→` | Навигация |
| `Enter` / `Space` | Выбрать пункт |
| `Esc` | Назад |
| `Ctrl+Alt+Del` | Аппаратная перезагрузка |
| `Alt+F11` | Reset эмулируемой машины |

## Файлы

| Клавиши | Действие |
|----------|----------|
| `Alt+L` | Загрузить файл |
| `Alt+F3` | Загрузить и запустить |
| `Alt+A` | Диск A |
| `Alt+B` | Диск B |
| `Alt+F4` | Подключить HDD |
| `Alt+E` | Открыть RAM-диск |
| `Shift+Alt+E` | Второй RAM-диск |
| `Alt+O` | Сохранить RAM-диск |
| `Shift+Alt+O` | Сохранить второй RAM-диск |

## Видео

| Клавиши | Действие |
|----------|----------|
| `Alt+C` | Цвет / монохром |
| `Alt+V` | Обрезка видимой области |

## Снимки состояния

| Клавиши | Действие |
|----------|----------|
| `Left Win + F1...F12` | Сохранить |
| `Right Win + F1...F12` | Загрузить |

## Смещение изображения

| Клавиши | Действие |
|----------|----------|
| `Numpad *` `/` | Горизонтальное смещение |
| `Numpad +` `-` | Вертикальное смещение |

Если открыто меню, эти же клавиши перемещают меню по экрану.

---

# Настройки

Настройки сохраняются на SD-карте и изменяются через экранное меню (OSD).

Для каждого видеорежима отдельно сохраняется положение изображения на экране.

---

# Поддерживаемые видеорежимы

- VGA
- HDMI-DVI
- RGB-TV
- TV-SOFT PAL
- TV-SOFT NTSC
